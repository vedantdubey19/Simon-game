🎮 Simon Game

A classic memory-based color sequence game built using HTML, CSS, and JavaScript.
The game challenges players to remember and repeat an increasingly long sequence of colors.

⸻

🚀 Demo

Play the game by opening index.html in your browser.

⸻

🧠 How the Game Works
	1.	Press any key to start the game.
	2.	The game will highlight a random color.
	3.	Repeat the sequence by clicking the buttons.
	4.	Each level adds a new color to the sequence.
	5.	If you click the wrong color, the game ends.
